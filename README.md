# SONAR（声呐）· AI 资讯趋势雷达

> 自动采集多来源 AI 资讯 → 大模型摘要与分类 → **以趋势分析为核心输出**的个人情报工具。

## 它解决什么

资讯聚合工具已经很多，但它们大多解决"看不完"（过滤 + 推送）。
本项目解决的是另一个问题：**看不出变化** —— 某个方向在升温还是降温？哪些事件是真的重要？

## 本地跑起来

```bash
# 1) 后端（Node 22.6+，TS 直跑无需构建）
cd server
npm install
cp .env.example .env          # 填 DEEPSEEK_API_KEY；不填也能跑（走启发式兜底）
npm run collect               # 采集一轮
npm run process               # AI 加工：分类 + 打分 + 高分条目深加工
npm start                     # 起服务 http://127.0.0.1:3001/api/news/health

# 2) 前端（另一个终端）
npm install
npm run dev                   # http://localhost:5173（已代理 /api → 3001）
```

## 目录结构

```
server/                后端（Node 22 + Fastify + node:sqlite）
  src/collector/       采集：fetch（超时/重试/UA）→ parse（RSS/Atom/RDF）→ 指纹去重 → 落库
  src/ai/              两阶段加工：批量分类打分 → 高分条目深度摘要与实体抽取（+ 启发式兜底）
                        每日简报生成（AI 不可用时自动降级为统计版）
  src/analytics/       事件聚类（SimHash 相似度 ≥0.75）+ 趋势四层（14 天滑动 z-score 突发检测）
  src/routes/          /api/news/* 接口
  test/                node:test 单元测试
src/（根目录）          前端 React + Vite + Tailwind，**图表全部手写 SVG**
docs/                  内部设计文档（不进版本控制）
```

## 常见问题

- **Windows 上 `npm run build` / `npm test` 报 `Cannot find module @rollup/rollup-win32-x64-msvc`**
  —— rollup 的原生二进制是 optional 依赖，偶尔装不上（尤其安装中途断过网）。补一句即可：
  `npm i @rollup/rollup-win32-x64-msvc --no-save`（不要写进 package.json，会绑死平台）。
- **页面显示「后端未连接」** —— 先 `cd server && npm start`，再确认 `curl http://127.0.0.1:3001/api/news/health` 有返回。

## 差异化在哪

现有同类项目几乎都停在"数条数"（假趋势：源一变多数字就涨）。本项目落点在**第四层**：

- **跨源交叉度** —— 同一条消息被几家独立源报道，这个数字本身就是重要性信号：
  它比 LLM 打分更客观（打分是主观判断，这是硬事实），而且是**聚合才有的视角**
- **突发检测** —— 某分类偏离基线 N 个标准差 → 提示"可能出大事了"
- **反向收益** —— 趋势数据可以补上"排序器没有记忆"的缺陷，反过来改善排序质量

## 合规边界

个人主体**非经营性 ICP 备案**，以下为硬约束：

- 只抓 RSS / 官方 API，不爬网页正文、不绕反爬
- 只存**标题 + 摘要 + 原文链接**，不存全文
- **登录后可见**，不面向公众 —— 且**注册入口必须关闭**，否则拦截失效
- 若将来要公开，只公开趋势统计图

> **关键区分**：ICP 备案管的是「域名是否解析到境内服务器」，**与是否公开无关**；
> 「登录拦截」挡的是**新闻信息服务许可**那一层（个人无法取得该许可）。
> 两者是不同层级的门槛，别混为一谈。（合规检查清单为内部文档，未随仓库发布。）

**上线前必须完成的三件事**（缺一即"面向公众"）：
① 关闭注册入口 ② 未登录时前端也不下发（Nginx 拦截 + `/api/*` 全鉴权）③ `robots.txt` + `noindex`。
前端 `index.html` 已内置 `noindex` meta；后端 `src/auth.ts` 已实现 `cd_session` 鉴权（配置 `JWT_SECRET` 后自动生效）。
